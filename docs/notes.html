1. Introduction to React

What is React?
React is a JavaScript library for building user interfaces, developed by Facebook. It allows you to create reusable UI components and efficiently update the DOM using a Virtual DOM.

Key Features

  • Component-Based: Build encapsulated components that manage their own state
  • Virtual DOM: Efficiently updates only what needs to change
  • Declarative: Describe what the UI should look like, React handles the rest
  • One-Way Data Flow: Data flows from parent to child via props

Creating a React App

# Using Create React App
npx create-react-app my-app
cd my-app
npm start

# Using Vite (faster alternative)
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

2. JSX Syntax

What is JSX?
JSX (JavaScript XML) is a syntax extension that allows you to write HTML-like code in JavaScript. It makes React code more readable and expressive.

Basic JSX Rules

Rule Example
Must return single parent element Wrap in <div> or <></>
Use className instead of class <div className="box">
All tags must be closed <img />, <br />
JavaScript expressions in curly braces {variable}, {2 + 2}

Example Syntax

const Greeting = () => {
    const name = "Student";
    const isLoggedIn = true;
    
    return (
        <div className="greeting">
            <h1>Hello, {name}!</h1>
            <p>Status: {isLoggedIn ? "Online" : "Offline"}</p>
            <img src="avatar.png" alt="User" />
        </div>
    );
};
💡 Tip: Use React Fragments <>...</> to avoid adding extra DOM nodes when wrapping multiple elements.

3. Components

What are Components?
Components are the building blocks of React applications. They are reusable pieces of UI that can accept inputs (props) and return React elements describing what should appear on screen.

Functional Component (Recommended)

// Simple functional component
function Welcome() {
    return <h1>Welcome to React!</h1>;
}

// Arrow function syntax
const Welcome = () => {
    return <h1>Welcome to React!</h1>;
};

// Using the component
function App() {
    return (
        <div>
            <Welcome />
            <Welcome />
        </div>
    );
}

Class Component (Legacy)

import React, { Component } from 'react';

class Welcome extends Component {
    render() {
        return <h1>Welcome to React!</h1>;
    }
}
⚠️ Note: Always start component names with a capital letter. React treats lowercase names as DOM tags.

4. Props (Properties)

What are Props?
Props are read-only inputs passed from parent to child components. They allow components to be dynamic and reusable by customizing their behavior and appearance.

Passing and Receiving Props

// Parent Component - passing props
function App() {
    return (
        <div>
            <UserCard 
                name="John Doe" 
                age={25} 
                isActive={true} 
            />
        </div>
    );
}

// Child Component - receiving props
function UserCard(props) {
    return (
        <div className="card">
            <h2>{props.name}</h2>
            <p>Age: {props.age}</p>
            <p>Status: {props.isActive ? "Active" : "Inactive"}</p>
        </div>
    );
}

// With destructuring (cleaner)
function UserCard({ name, age, isActive }) {
    return (
        <div className="card">
            <h2>{name}</h2>
            <p>Age: {age}</p>
        </div>
    );
}

Default Props

function Button({ text = "Click Me", color = "blue" }) {
    return (
        <button style={{ backgroundColor: color }}>
            {text}
        </button>
    );
}
⚠️ Important: Props are read-only! Never modify props directly inside a component.

5. State (useState Hook)

What is State?
State is data that can change over time within a component. When state changes, React re-renders the component to reflect the new data. The useState hook is used to add state to functional components.

Basic useState Syntax

import { useState } from 'react';

function Counter() {
    // Syntax: const [stateValue, setterFunction] = useState(initialValue);
    const [count, setCount] = useState(0);
    
    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(count + 1)}>
                Increment
            </button>
        </div>
    );
}

Different State Types

function StateExamples() {
    // Number
    const [count, setCount] = useState(0);
    
    // String
    const [name, setName] = useState("");
    
    // Boolean
    const [isVisible, setIsVisible] = useState(false);
    
    // Array
    const [items, setItems] = useState([]);
    
    // Object
    const [user, setUser] = useState({ name: "", age: 0 });
    
    // Updating array (add item)
    const addItem = () => {
        setItems([...items, "New Item"]);
    };
    
    // Updating object
    const updateUser = () => {
        setUser({ ...user, name: "John" });
    };
}
💡 Tip: Always use the setter function to update state. Never modify state directly like count = count + 1.

6. Event Handling

What is Event Handling?
React handles events using camelCase syntax and passes functions as event handlers. Events work similarly to DOM events but with React's synthetic event system.

Common Event Types

Event Description
onClickWhen element is clicked
onChangeWhen input value changes
onSubmitWhen form is submitted
onMouseEnterWhen mouse enters element
onMouseLeaveWhen mouse leaves element
onFocusWhen element receives focus
onBlurWhen element loses focus

Event Handler Examples

function EventExamples() {
    // Basic click handler
    const handleClick = () => {
        alert("Button clicked!");
    };
    
    // Handler with event object
    const handleChange = (event) => {
        console.log(event.target.value);
    };
    
    // Handler with parameters
    const handleItemClick = (id) => {
        console.log("Item clicked:", id);
    };
    
    return (
        <div>
            <button onClick={handleClick}>Click Me</button>
            
            <input onChange={handleChange} />
            
            <button onClick={() => handleItemClick(5)}>
                Item 5
            </button>
        </div>
    );
}
⚠️ Note: When passing a function with parameters, wrap it in an arrow function: onClick={() => handleClick(id)}

7. useEffect Hook

What is useEffect?
The useEffect hook lets you perform side effects in functional components. Common uses include: fetching data, setting up subscriptions, and manually changing the DOM.

useEffect Patterns

import { useState, useEffect } from 'react';

function EffectExamples() {
    const [data, setData] = useState(null);
    const [count, setCount] = useState(0);
    
    // Runs on EVERY render
    useEffect(() => {
        console.log("Rendered!");
    });
    
    // Runs ONCE on mount (empty dependency array)
    useEffect(() => {
        console.log("Component mounted!");
        // Good for: API calls, subscriptions
    }, []);
    
    // Runs when 'count' changes
    useEffect(() => {
        console.log("Count changed to:", count);
    }, [count]);
    
    // With cleanup function
    useEffect(() => {
        const timer = setInterval(() => {
            console.log("Tick");
        }, 1000);
        
        // Cleanup: runs on unmount
        return () => clearInterval(timer);
    }, []);
}

Fetching Data Example

function UsersList() {
    const [users, setUsers] = useState([]);
    const [loading, setLoading] = useState(true);
    
    useEffect(() => {
        fetch('https://api.example.com/users')
            .then(response => response.json())
            .then(data => {
                setUsers(data);
                setLoading(false);
            });
    }, []);
    
    if (loading) return <p>Loading...</p>;
    
    return (
        <ul>
            {users.map(user => (
                <li key={user.id}>{user.name}</li>
            ))}
        </ul>
    );
}

8. Conditional Rendering

What is Conditional Rendering?
Conditional rendering allows you to render different UI elements based on certain conditions. React uses JavaScript operators like ternary (? :) and logical AND (&&).

Conditional Rendering Methods

function ConditionalExamples({ isLoggedIn, messages, user }) {
    return (
        <div>
            {/* Method 1: Ternary Operator */}
            {isLoggedIn ? (
                <p>Welcome back!</p>
            ) : (
                <p>Please log in</p>
            )}
            
            {/* Method 2: Logical AND (&&) */}
            {messages.length > 0 && (
                <span>You have {messages.length} messages</span>
            )}
            
            {/* Method 3: Early return */}
            {!user && return <p>No user found</p>}
        </div>
    );
}

// Method 4: If-else inside component
function StatusMessage({ status }) {
    if (status === "loading") {
        return <p>Loading...</p>;
    }
    if (status === "error") {
        return <p>Error occurred!</p>;
    }
    return <p>Success!</p>;
}

9. Lists & Keys

Rendering Lists
Use the map() method to transform arrays into lists of elements. Each item needs a unique key prop to help React identify which items have changed.

Basic List Rendering

function FruitList() {
    const fruits = ["Apple", "Banana", "Orange"];
    
    return (
        <ul>
            {fruits.map((fruit, index) => (
                <li key={index}>{fruit}</li>
            ))}
        </ul>
    );
}

// With objects (use unique id as key)
function UserList() {
    const users = [
        { id: 1, name: "Alice", role: "Admin" },
        { id: 2, name: "Bob", role: "User" },
        { id: 3, name: "Charlie", role: "User" }
    ];
    
    return (
        <div>
            {users.map(user => (
                <div key={user.id} className="user-card">
                    <h3>{user.name}</h3>
                    <p>{user.role}</p>
                </div>
            ))}
        </div>
    );
}
⚠️ Important: Never use array index as key if the list can be reordered. Use unique IDs from your data instead.

10. Forms & Inputs

Controlled Components
In React, form elements are typically "controlled" - their values are driven by component state. This gives you full control over the form data.

Basic Form Example

import { useState } from 'react';

function LoginForm() {
    const [formData, setFormData] = useState({
        email: "",
        password: ""
    });
    
    const handleChange = (e) => {
        const { name, value } = e.target;
        setFormData(prev => ({
            ...prev,
            [name]: value
        }));
    };
    
    const handleSubmit = (e) => {
        e.preventDefault(); // Prevent page refresh
        console.log("Form submitted:", formData);
    };
    
    return (
        <form onSubmit={handleSubmit}>
            <input
                type="email"
                name="email"
                value={formData.email}
                onChange={handleChange}
                placeholder="Email"
            />
            
            <input
                type="password"
                name="password"
                value={formData.password}
                onChange={handleChange}
                placeholder="Password"
            />
            
            <button type="submit">Login</button>
        </form>
    );
}

Different Input Types

// Checkbox
<input
    type="checkbox"
    checked={isChecked}
    onChange={() => setIsChecked(!isChecked)}
/>

// Select dropdown
<select value={selected} onChange={(e) => setSelected(e.target.value)}>
    <option value="option1">Option 1</option>
    <option value="option2">Option 2</option>
</select>

// Textarea
<textarea
    value={text}
    onChange={(e) => setText(e.target.value)}
    rows="4"
/>
💡 Tip: Always use e.preventDefault() in form submit handlers to prevent the default page refresh behavior.
